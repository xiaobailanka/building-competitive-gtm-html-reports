# Reproducible production method

This file captures the transferable method used to create the golden report. It is a production playbook, not private chain-of-thought.

## Phase A — Frame before searching

Write a 5-line research brief:

- product / SKU family;
- direct competitor / SKU family;
- market and date;
- primary business decision;
- expected deliverable.

Then write the first hypothesis map: where are likely differences in user job, price, product, message, channel, and conversion? Treat these as questions, not conclusions.

## Phase B — Build the evidence ledger

Search in passes rather than randomly:

1. official product/spec/press pages for both brands;
2. launch price and SKU architecture;
3. market/category context;
4. reviews/tests and user/community evidence;
5. retailer/channel benefits;
6. platform/content evidence;
7. early sell-through only if traceable.

For each source, immediately record what claim it can and cannot support.

## Phase C — Normalize comparisons

Create a normalized product table first. Align:

- equivalent SKU tier;
- memory/storage;
- announced vs shipping status;
- geography;
- units and measurement conditions.

This catches many false conclusions before writing.

## Phase D — Convert features into user jobs

For each material spec difference ask:

1. What user task changes?
2. Is the difference visible in daily use?
3. Can a creator or store demonstrate it in <15 seconds?
4. Does it reduce risk, effort, time, or cost?
5. Does it justify price or switching now?

If a spec has no credible user consequence, keep it in the table but do not elevate it as a headline selling point.

## Phase E — Identify mental territory

Distill each brand to one sentence:

`Brand wants to be chosen when the consumer values ____ because ____.`

Then decide whether to compete head-on or create an orthogonal position. Prefer a territory where the target already has product proof.

## Phase F — Rebuild the consumer funnel

Work backward from purchase:

- What must be true for checkout?
- What comparison resolves uncertainty?
- What search question gets asked?
- What content creates the question?
- What exposure makes the product memorable?

This prevents channel tactics from becoming disconnected from conversion.

## Phase G — Turn insight into operating actions

For each conclusion force this syntax:

`Because [evidence], consumers may [behavior]. Therefore [strategy]. Execute [specific action]. Validate with [metric/test].`

If the statement cannot be completed, it is probably too vague.

## Phase H — Design the page around reading speed

1. Put conclusion before evidence detail.
2. Alternate dense tables with visual cards to manage cognitive load.
3. Use color only to distinguish target/competitor/priority/risk.
4. Put caveats adjacent to charts.
5. Use the source appendix for auditability, but repeat source scope near critical numbers.
6. End with one-page causal chain so the reader can remember the decision.

## Phase I — QA

Run three reviews:

### Research QA

- every important number traceable;
- rumors clearly separated;
- no incompatible comparisons;
- user claims not overgeneralized.

### Strategy QA

- clear competitor choice;
- clear “do not copy” rule;
- each major insight has an action;
- recommendations exploit real product proof.

### HTML QA

- local open works;
- Chinese encoding correct;
- desktop/mobile readable;
- tables scroll on mobile;
- print works;
- no external dependency required;
- no placeholders remain.
